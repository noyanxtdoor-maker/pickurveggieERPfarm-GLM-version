# Quality Gates Checklist

Before merging any feature:

## Security

- Permissions verified
- RLS policies tested
- Data protection validated

---

## Operations

- Inventory balances correct
- Batch tracking works
- Production records match physical events

---

## Financial

- Journal entries balance
- COGS calculations verified
- Reports reconcile

---

## User Experience

- Tablet usability tested
- Offline operation tested
- Synchronization tested
