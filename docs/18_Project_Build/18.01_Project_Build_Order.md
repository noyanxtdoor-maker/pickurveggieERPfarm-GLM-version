# Project Build Order

Development must follow dependency order.

## Phase 1 — System Foundation

1. Authentication
2. User accounts
3. Role-based access control (RBAC)
4. Permissions engine
5. User personal workspaces

---

## Phase 2 — Master Data

Create the foundation tables:

- Farm locations
- Greenhouses
- Crop varieties
- Units of measurement
- Suppliers
- Customers
- Employees
- Equipment

---

## Phase 3 — Inventory Engine

Build:

- Item master
- Stock receiving
- Batch tracking
- FIFO engine
- Unit conversion
- Stock movement ledger
- Consumption terminal
- Transfers
- Spoilage

---

## Phase 4 — Production Engine

Build:

- Crop blocks
- Nursery
- Transplanting
- Fertigation
- Harvest events
- Production costs
- Biological assets

---

## Phase 5 — Sales Engine

Build:

- POS
- Wholesale
- Pre-orders
- Deliveries
- Customer ledger
- Accounts receivable

---

## Phase 6 — Accounting Engine

Build:

- Chart of accounts
- Journal engine
- General ledger
- Accounts payable
- Cash management
- Financial reports

---

## Phase 7 — Intelligence

Build:

- Dashboards
- Crop profitability
- Cost/kg analysis
- ROI comparisons
- Forecasting
