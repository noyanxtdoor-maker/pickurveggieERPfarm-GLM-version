# Coding Standards

Technology stack:

Frontend:
- React
- Vite
- TypeScript

Backend:
- Supabase
- PostgreSQL

Mobile:
- Capacitor Android

---

## Principles

- Strong TypeScript typing
- Reusable components
- No duplicated business logic
- Clear file structure
- Proper error handling
- Clean documentation

---

## Architecture

UI Components → Service Layer → Database

Never place business logic directly inside UI components.
