# Farm Operations Entity Relationship Layer

## Purpose

This section defines the digital representation of the physical farm.

The ERP must mirror the real-world structure of the farm, from the company level down to individual crops and activities.

Every plant, growing area, and farm operation must be traceable.

---

# Farm Hierarchy

## Master Relationship

The farm structure follows:

Company

↓

Farm Location

↓

Production Zone

↓

Crop Block

↓

Crop Cycle

↓

Production Events

↓

Harvest Batch

---

# Farm Location Entity

## Purpose

A farm location represents a physical farming site owned or managed by a company.

Examples:

SmartIsland AgriTech Farm - Siargao

Future:
- Dinagat Farm
- Cebu Farm
- Bohol Farm

---

## Farm Location Records

Each farm stores:

- Farm ID
- Farm name
- Address
- GPS coordinates
- Farm size
- Land ownership type
- Farm manager
- Operating status

---

# Production Zone Entity

## Purpose

A production zone is a major subdivision inside a farm.

Examples:

- Greenhouse A
- Greenhouse B
- Nursery Area
- Open Field
- Hydroponic Area
- Eggplant Tunnel Area

---

## Production Zone Records

Each zone stores:

- Zone ID
- Zone name
- Zone type
- Area size
- Environmental characteristics
- Assigned supervisors
- Current operational status

---

# Crop Block Entity

## Purpose

A crop block represents a specific production area where a crop cycle is planted.

Examples:

Farm:
Siargao Farm

Zone:
Greenhouse A

Block:
Lettuce Block 01

---

## Crop Block Records

The system stores:

- Block ID
- Block name
- Crop assigned
- Variety assigned
- Growing system

Examples:

- Soil
- Hydroponics
- Cocopeat growbags
- DFG System
- Gomez Method Hydroponics

---

Additional records:

- Planting date

- Actual harvest date
- Number of plants
- Plant spacing
- Growing medium
- Responsible workers
- Current status

- Pesticide application

- Harvesting

## Production Event Records

Each event stores:

- Related farm location

# Farm Operation Audit Rule

Every physical farm activity must answer:

What happened?

↓

Where did it happen?

↓

When did it happen?

↓

Who performed it?

↓

Which materials were used?

↓

What was the result?
