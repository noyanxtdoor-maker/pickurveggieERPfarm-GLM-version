# Project Overview

PickUrVeggie ERP V3 is a tablet-first agricultural ERP designed for real farm operations.

Core users (simplified V1/V2 operational view):
- Owner
- Co-owner
- Admin
- Operator
- Employee

> **Canonical role model (Stage A · ADR-001).** The list above is the legacy simplified view. The **canonical, data-driven role & permission model** is defined in [`11.01_RBAC`](../11_Security_Access_Control/11.01_Role_Based_Access_Control_RBAC.md) and [`20.03`](../20_Supabase_Master_Database_Schema/20.03_User_Accounts_Roles_Permissions.md). Roles are **seed data, not a fixed list**, and authorization is **permission-based, never role-name-based** (audit findings P3-03, P4-05).

Mission:
Create a complete seed-to-sale, accounting-integrated, privacy-respecting agricultural ERP.
