# 11.05 User Session and Device Management

## Purpose

PickUrVeggie ERP V3 shall maintain secure control over user sessions, devices, and authentication states across web and mobile platforms.

The system shall ensure that only authorized users, approved devices, and valid sessions can access company information.

---

# Authentication Model

User identity shall be managed using secure authentication services.

Authentication shall support:

- Email and password login
- Secure password hashing
- Session tokens
- Password recovery
- Multi-device login
- Future support for multi-factor authentication (MFA)

Passwords shall never be stored as plain text.

---

# Device Registration

Each device connecting to PickUrVeggie ERP V3 shall have a unique device identity.

Examples:

Device 1:

User:
Juan Dela Cruz

Device:
Samsung Galaxy A55

Type:
Mobile

Branch:
Siargao Farm

---

Device 2:

User:
Juan Dela Cruz

Device:
Windows Laptop

Type:
Desktop

Branches Available:
- Siargao Farm
- Cebu Farm

---

The system shall record:

- Device ID
- Device name
- Device type
- Operating system
- Application version
- First login date
- Last active date
- Current session status

---

# Device Trust Management

The system shall support trusted and untrusted devices.

Trusted devices may:

- Stay logged in longer
- Use offline functionality
- Synchronize local data

Untrusted devices may:

- Have shorter sessions
- Require additional authentication

High-risk actions may require re-authentication.

Examples:

- Changing passwords
- Modifying permissions
- Exporting sensitive financial reports
- Approving major transactions

---

# Multi-Device Sessions

Users may log in from multiple devices simultaneously.

Example:

Owner:

- Office desktop
- Personal laptop
- Mobile phone

The system shall track each session independently.

---

# Session Information

Every active session shall maintain:

- User ID
- Company ID
- Device ID
- Login timestamp
- Last activity timestamp
- Current active branch
- User role within the active branch
- Session token identifier

---

# Branch Switching Security

Users with access to multiple branches may switch between authorized branches.

Example:

Juan Dela Cruz

Authorized:

✓ Siargao Branch  
✓ Cebu Branch

Not Authorized:

✗ Bohol Branch

Every branch switch shall be recorded in the audit log.

The system shall verify permissions every time the active branch changes.

---

# Session Expiration

The system shall automatically terminate inactive sessions.

Examples:

Low-risk sessions:
- Longer expiration period

High-risk sessions:
- Shorter expiration period

The system may force re-authentication for:

- Password changes
- Security policy changes
- Extended inactivity
- Suspicious login behavior

---

# Offline Device Security

Because PickUrVeggie ERP V3 supports offline operation:

A device may temporarily operate without internet access.

Offline mode shall follow these rules:

- Only previously authenticated users may access offline data
- Offline data shall be limited to authorized branches
- Offline records shall be digitally linked to the user who created them
- Local data shall synchronize securely when connectivity returns

A user shall not gain access to new branches while offline.

Branch assignments and permissions must be synchronized from the server.

---

# Remote Session Control

Authorized users may manage active sessions.

Examples:

Users may:

- View their active devices
- Log out old devices
- Remove trusted devices

Administrators may:

- Force logout compromised accounts
- Disable lost devices
- Terminate suspicious sessions

---

# Suspicious Activity Detection

The system shall monitor events such as:

- Multiple failed login attempts
- Login from unfamiliar devices
- Login from unusual locations
- Rapid switching between many branches
- Unusual data export activity

High-risk events may trigger:

- Security alerts
- Temporary account restrictions
- Additional identity verification

---

# Device Data Protection

Sensitive information stored on devices shall be protected.

Protection mechanisms may include:

- Encrypted local storage
- Secure session storage
- Automatic logout policies
- Data removal after account revocation

---

# Future Security Enhancements

The architecture shall support:

- Multi-factor authentication (MFA)
- Biometric login
- Hardware security keys
- Device reputation scoring
- Advanced threat monitoring

---

# Architecture Rule

No device shall access PickUrVeggie ERP V3 without validating:

- User identity
- Company membership
- Branch authorization
- Assigned role
- Session validity
- Device security status

All sessions and devices must remain traceable through the audit system.
