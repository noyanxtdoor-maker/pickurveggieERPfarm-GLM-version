# 20.27 File Attachments and Documents

## Purpose

The document management system stores files associated with business records.

Examples:

- Receipts
- Purchase orders
- Employee documents
- Equipment manuals
- Crop photos
- Inspection reports

---

# Storage Architecture

Files are stored using secure cloud storage.

Examples:

- Supabase Storage

The database stores only file metadata.

---

# documents Table

Fields:

Identification:

- id
- company_id
- branch_id

File Information:

- file_name
- original_name
- file_type
- file_size
- storage_path

Ownership:

- uploaded_by
- upload_date

Relationship:

- related_entity_type
- related_entity_id

Examples:

Entity Types:

- Purchase Order
- Employee
- Equipment
- Crop Block
- Harvest Batch

---

# Version Control

The system shall support:

- Document replacement history
- Version tracking
- Change records

---

# Security Rules

Document access follows:

- Company access
- Branch access
- Role permissions

---

# Architecture Rule

A file can never bypass ERP security by using a direct storage link.
