# 20.29 Offline Synchronization Queue

## Purpose

The synchronization engine allows PickUrVeggie ERP V3 to continue operating during internet outages.

---

# Offline Architecture

Device
 ↓
Local Database
 ↓
Sync Queue
 ↓
Supabase Cloud Database

---

# sync_queue Table

Fields:

Identification:

- id
- device_id
- user_id
- company_id
- branch_id

Operation:

- entity_type
- entity_id
- operation_type

Examples:

- Create
- Update
- Delete

---

Data:

- payload
- local_timestamp
- server_timestamp

---

Status:

- Pending
- Synced
- Failed
- Conflict

---

# Conflict Resolution

The system shall support:

- Conflict detection
- User review of conflicts
- Approval for sensitive conflicts

Critical records such as financial transactions shall require stricter conflict handling.

---

# Security Rules

Offline devices shall:

- Access only previously authorized data
- Maintain encryption when possible
- Preserve audit information

---

# Architecture Rule

Synchronization shall never bypass company, branch, or permission security.
