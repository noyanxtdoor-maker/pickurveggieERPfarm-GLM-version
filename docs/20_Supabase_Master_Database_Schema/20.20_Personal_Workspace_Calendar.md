# 20.20 Personal Workspace Calendar

## Purpose

Each user has a private calendar workspace integrated with the company calendar system.

---

# personal_calendar Table

Stores user-specific information.

Examples:

- Personal reminders
- Private notes
- Personal tasks
- Follow-up reminders

---

Fields:

- id
- user_id
- title
- description
- reminder_datetime
- recurring_rule
- status

---

# Calendar Views

Users may view:

## Personal View

Only their private events.

## Assigned Work View

Shows company events assigned to them.

## Branch View

Available only if their role allows access.

## Corporate View

Available to global management roles.

---

# Privacy Rules

Private calendar entries are visible only to the owner unless explicitly shared.

Managers do not automatically have access to employee private calendars.

---

# Architecture Rule

Personal productivity data shall never bypass company security boundaries.
