# 20.04 User Workspaces and Private Data

## Purpose

PickUrVeggie ERP V3 provides every user with a personal workspace while keeping company and branch information securely separated.

Personal workspaces allow users to manage their own settings, tasks, preferences, and private information.

---

# Workspace Philosophy

The ERP contains two categories of information:

## 1. Organizational Data

Belongs to:

- Company
- Branch

Examples:

- Inventory
- Accounting
- Production
- Employees
- Sales
- Equipment


Access depends on:

- Role
- Branch assignment
- Permissions

---

## 2. Personal Data

Belongs to an individual user.

Examples:

- Personal dashboard settings
- Notifications
- Calendar preferences
- UI themes
- Saved filters
- Personal notes
- Draft records

---

# User Preferences Table

Table: user_preferences


Fields:

- id
- user_id
- default_branch_id
- preferred_language
- timezone
- theme
- dashboard_layout
- notification_preferences
- created_at
- updated_at

---

# Personal Dashboard Configuration

Users may customize:

- Widgets
- Layout
- Favorite reports
- Frequently used modules
- Default landing page

Example:

Branch Supervisor:

Default Dashboard:
Siargao Inventory Overview


Owner:

Default Dashboard:
All Branch Financial Summary

---

# Personal Notes and Drafts

The system may include:

Table: user_private_records


Examples:

- Personal reminders
- Draft reports
- Draft requests
- Saved searches


Fields:

- id
- user_id
- record_type
- content
- created_at
- updated_at

---

# Branch Context Memory

Users with access to multiple branches may define:

- Default branch after login
- Preferred dashboards per branch
- Frequently accessed branches

The system shall remember preferences but shall never grant access to unauthorized branches.

---

# Privacy Rules

A user's private workspace shall only be accessible to:

- The user
- Authorized administrators when required by company policy and security procedures

Managers shall not automatically access employee private notes or preferences.

---

# Offline Workspace Support

User workspace data may be cached locally for offline operation.

Offline data must:

- Remain encrypted when possible
- Synchronize securely
- Respect user permissions

---

# Architecture Rule

Personal convenience settings shall never override security rules.

A saved preference for a branch, dashboard, or report shall only work if the user currently has authorization to access that resource.
