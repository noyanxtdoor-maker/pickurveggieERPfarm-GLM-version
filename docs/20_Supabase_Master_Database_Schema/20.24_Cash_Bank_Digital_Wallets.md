# 20.24 Cash, Bank and Digital Wallets

## Purpose

The system manages all company monetary accounts.

Examples:

- Cash on Hand
- Bank Accounts
- GCash
- Maya
- Other Digital Wallets

---

# financial_accounts Table

Fields:

- id
- company_id
- branch_id
- account_name
- account_type

Types:

- Cash
- Bank
- Digital Wallet

---

Additional Fields:

- bank_name
- account_number
- currency
- current_balance
- status

---

# Transaction Records

Every movement of money must record:

- Deposit
- Withdrawal
- Transfer
- Payment
- Receipt

Each transaction links to:

- Journal Entry
- User
- Branch
- Supporting documents

---

# Cash Reconciliation

The system supports:

- Daily cash counting
- Bank reconciliation
- Difference investigation

---

# Multi-Branch Cash Control

Example:

Siargao Branch:

Cash:
₱50,000

GCash:
₱15,000


Cebu Branch:

Cash:
₱20,000


Corporate users can view:

- Individual branch balances
- Consolidated balances

---

# Architecture Rule

Cash balances shall be calculated from transaction history.

Manual changes to balances are prohibited.
