# 20.26 Notifications and Messaging

## Purpose

The notification system delivers important alerts, reminders, approvals, and communications to users based on their company, branch, role, and permissions.

---

# Notification Types

The system supports:

Operational:

- Crop activity reminders
- Harvest schedules
- Fertigation schedules
- Maintenance reminders

Business:

- Purchase approvals
- Inventory low-stock warnings
- Overdue payments
- Delivery status updates

Security:

- Login alerts
- Permission changes
- Suspicious activities

---

# notifications Table

Fields:

Identification:

- id (UUID)
- company_id
- branch_id

Recipient Information:

- recipient_user_id
- sender_user_id

Notification Details:

- notification_type
- title
- message
- priority

Priority:

- Low
- Normal
- High
- Critical

Status:

- Unread
- Read
- Archived

Delivery Information:

- delivery_channel

Channels:

- In-App
- Email
- SMS
- Push Notification

Audit:

- created_at
- read_at

---

# Messaging System

The ERP may support internal communication.

Examples:

- Supervisor → Worker
- Manager → Branch Team
- Corporate → All Branches

---

# messages Table

Fields:

- id
- company_id
- branch_id
- sender_id
- recipient_id
- subject
- message_content
- sent_at
- read_at

---

# Notification Security

Users shall receive only messages and notifications they are authorized to access.

---

# Architecture Rule

Notifications must respect company isolation, branch boundaries, and user permissions.
