# 20.08 Inventory Batches and FIFO Management

## Purpose

Inventory batches track individual quantities of an item based on their acquisition date, source, cost, and expiration.

This enables:

- FIFO inventory consumption
- Lot traceability
- Expiration monitoring
- Cost tracking
- Supplier tracking

---

# Inventory Batch Concept

Example:

Item:
Calcium Nitrate

Branch:
Siargao Farm


Batch A:

Received:
January 1, 2026

Quantity:
50 kg

Cost:
₱80/kg


Batch B:

Received:
February 1, 2026

Quantity:
100 kg

Cost:
₱90/kg


When consuming 30 kg:

The system uses:

Batch A first.

Remaining:

Batch A:
20 kg

Batch B:
100 kg

# FIFO Consumption Rule

The default inventory costing method shall be:

FIFO (First In, First Out).

The oldest available batch shall be consumed first.

Example:

Batch 001:
50 kg

Batch 002:
100 kg


Consumption:
70 kg


Result:

Batch 001:
0 kg

Batch 002:
80 kg

---

# Expiration Management

The system shall monitor:

- Expired batches
- Near-expiry batches
- Unsafe inventory

Example alerts:

⚠ Fertilizer expires in 30 days.

⚠ Seed germination validity approaching expiration.

---

# Batch Traceability

The system shall answer:

Where did this material come from?

Answer:

- Supplier
- Purchase order
- Receiving record
- Batch number
- Date received
- Cost

---

# Agricultural Traceability

Example:

Tomato Harvest Batch H001

Used:

Fertilizer Batch:
FERT-CALN-001

Seed Batch:
TOM-RM-2026-01


The ERP shall support tracing inputs used during production.

---

# Architecture Rule

Every inventory item requiring traceability shall use batch records.

No batch quantity shall be modified without a corresponding inventory movement record.
