# 20.14 Production Events

## Purpose

Production events record every activity performed during a crop's lifecycle.

This creates complete agricultural history.

---

# production_events Table

Fields:

Identification:

- id
- company_id
- branch_id
- crop_block_id

Event Information:

- event_type

Examples:

- Seeding
- Transplanting
- Fertigation
- Irrigation
- Pruning
- Pest Control
- Disease Treatment
- Environmental Adjustment
- Inspection
- Harvest

---

Event Details:

- event_date
- description
- performed_by
- supervised_by

---

Resource Consumption:

- inventory_movement_id

Examples:

Fertigation:

Calcium Nitrate:
3 kg

Potassium Nitrate:
2 kg

The system links these to inventory deductions.

---

Environmental Data:

- temperature
- humidity
- pH
- EC
- weather_conditions

---

Cost Tracking:

- labor_hours
- labor_cost
- equipment_cost

---

Attachments:

- photos
- sensor_data_links
- notes

---

# Automation Integration

Future IoT devices may automatically create production events.

Examples:

- Irrigation completed
- Nutrient dosing completed
- Environmental warning

---

# Architecture Rule

If a crop activity occurred, it must have a production event record.
