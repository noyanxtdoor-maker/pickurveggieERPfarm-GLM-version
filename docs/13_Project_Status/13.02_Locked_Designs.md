# 13.02 — Locked Designs

> **Canonical registry (Stage A · ADR-001).** This document is the **single authoritative locked-designs registry** for PickUrVeggie ERP V3. All other documents (notably `19.02_Architecture_Protection_Rules`) reference this list rather than maintaining their own. It reconciles the previously divergent lists in `13.02` and `19.02` (audit finding P1-02).

The following design decisions are locked unless a critical flaw is found:

- POS and sales workflows
- Inventory movement ledger (movement system)
- Fast resource consumption terminal
- Batch and FIFO logic (FIFO batch tracking)
- Production cost allocation (production cost engine)
- Dual calendar architecture (calendar privacy engine)
- Personal workspace privacy model
- Core UI language for tablet-first operation
- Role permissions model (reconciled from 19.02)
- Accounting relationships and posting integrity (reconciled from 19.02)

> **Recommended per-entry metadata (remediation):** each locked entry should record a *locked date*, *rationale*, and *unlock criteria*. Capturing this metadata is a follow-on remediation task; the reconciled list above is the authoritative set as of Stage A.
