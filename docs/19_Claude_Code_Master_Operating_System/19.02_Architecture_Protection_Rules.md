# Architecture Protection Rules

> **Authority note (Stage A · ADR-001).** The authoritative list of locked designs is maintained in the **single canonical registry [`13.02_Locked_Designs`](../13_Project_Status/13.02_Locked_Designs.md)**. This document defines the *protection rules*; it no longer maintains its own divergent list (audit finding P1-02). The examples below are retained for context only and are superseded by `13.02`.

Approved architecture is considered locked. See `13.02_Locked_Designs` for the canonical registry, which includes (among others):

- Inventory movement system
- FIFO batch tracking
- Production cost engine
- Calendar privacy engine
- Role permissions
- Accounting relationships

---

Do not remove or redesign these systems unless a critical defect is proven.

---

New features must integrate with existing architecture.
