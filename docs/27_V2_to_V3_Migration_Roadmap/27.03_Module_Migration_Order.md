# 27.03 Module Migration Order

## Purpose

This document defines the official order for migrating PickUrVeggie ERP V2 into the V3 enterprise architecture.

The migration order exists to prevent random development, protect working systems, and ensure that every new layer is built on a stable foundation.

---

# Migration Principle

The migration shall begin with the foundation of the ERP.

A common mistake is to start with farm operations, inventory, or accounting features before the identity and data foundation exists.

The V3 migration follows a foundation-first strategy.

---

# Phase 1 — Enterprise Core Foundation

Priority: CRITICAL

This phase establishes the identity and ownership model of the ERP.

Modules:

- Company Management
- Multi-tenant architecture
- User Accounts
- Authentication System
- Roles
- Permissions
- Role-Based Access Control (RBAC)
- Personal Workspaces

Reason:

Every future record in the ERP must know:

- Which company owns it
- Which user created it
- Who can access it
- Who can modify it

---

# Phase 2 — Data Architecture Layer

Priority: CRITICAL

Modules:

- Supabase PostgreSQL schema
- Database migrations
- Repository pattern
- Service layer
- API boundaries
- Offline synchronization queue
- Audit logging foundation

Reason:

The database foundation must exist before migrating business modules.

---

# Phase 3 — User Experience Architecture

Priority: HIGH

Modules:

- React Router navigation
- Layout system
- Dashboard shell
- Authentication guards
- Permission guards
- Mobile-first navigation
- Shared UI components

Reason:

The current App.tsx controller must be broken into a scalable application structure.

---

# Phase 4 — Master Data Migration

Priority: HIGH

Modules:

- Farms
- Production zones
- Crops
- Seed varieties
- Units of measurement
- Suppliers
- Customers
- Equipment master records

Reason:

Business transactions depend on master records.

---

# Phase 5 — Inventory System Migration

Priority: HIGH

Modules:

- Inventory items
- Batch management
- Stock movements
- FIFO engine
- Traceability

Reason:

Inventory is the backbone of agricultural operations.

---

# Phase 6 — Agricultural Production Migration

Priority: HIGH

Modules:

- Crop lifecycle
- Planting records
- Harvest records
- Crop losses
- Biological asset tracking

Reason:

This introduces agriculture-specific intelligence into the ERP.

---

# Phase 7 — Financial System Migration

Priority: CRITICAL

Modules:

- Chart of Accounts
- Journal Entries
- General Ledger
- Accounts Receivable
- Accounts Payable
- Cash Management
- Financial Statements

Reason:

Financial integrity must be preserved during migration.

---

# Phase 8 — Human Resources & Payroll Migration

Priority: MEDIUM

Modules:

- Employees
- Attendance
- Payroll computation
- Salary disbursement
- Performance records

---

# Phase 9 — Advanced Intelligence Layer

Priority: FUTURE EXPANSION

Modules:

- AI Assistant
- AI analytics
- Demand forecasting
- Crop recommendations
- Document understanding

---

# Phase 10 — IoT and Smart Farm Layer

Priority: FUTURE EXPANSION

Modules:

- Sensor devices
- ESP32 integration
- MQTT communication
- Environmental monitoring
- Automated alerts

---

# Phase 11 — Mobile Enterprise Application

Priority: FUTURE EXPANSION

Modules:

- Worker application
- Offline field operations
- Mobile synchronization
- Camera and document capture

---

# Migration Rules

The following rules are mandatory:

1. No module may migrate before its dependencies exist.

2. Existing V2 functionality must remain available until the V3 replacement is proven stable.

3. Every migration must include:
   - Database strategy
   - Security review
   - Offline synchronization design
   - Testing plan

4. Architecture documents inside `/docs` are the authority for all implementation decisions.

---

# Conclusion

PickUrVeggie ERP V3 will not be built by adding random features.

It will be built layer by layer:

Foundation → Data → Interface → Master Data → Operations → Intelligence

This sequence minimizes risk and ensures the system can scale into a true enterprise agricultural ERP platform.
